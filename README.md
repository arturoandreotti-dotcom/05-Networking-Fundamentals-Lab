# Networking Fundamentals Lab

## Overview

This project is part of my 10-project IT Infrastructure & Cloud portfolio.

The goal is to develop practical networking skills by designing, configuring, testing, and troubleshooting simulated networks.

The labs focus on fundamental networking concepts and realistic infrastructure administration tasks.
